# 김지후 포트폴리오 (초안)

## 작업 목표
중학생 포트폴리오용 자기소개 웹페이지 초안. 소개, 관심사, 활동/수상, 프로젝트를
한 페이지에 정리해 보여주는 것이 목표이며, 현재는 배포 전 구조/디자인 설계 단계다.

## 기술 스택
- HTML / CSS만 사용 (React, Next.js 등 프레임워크 미사용)
- 별도 빌드 도구·패키지 매니저 없음 — `index.html`을 브라우저에서 바로 열어 확인
- 단일 페이지 스크롤 구조 + 섹션 `id` 기반 앵커 내비게이션
  (`#home`, `#about`, `#interests`, `#activities`, `#projects`, `#contact`)

## 파일 구조
- `index.html` — 페이지 구조 및 콘텐츠
- `style.css` — 전체 스타일 (CSS 변수, 반응형 포함)

## 민감정보 제외 규칙
개인 식별이 가능한 정보 중 이름과 나이는 본인의 명시적 요청에 따라 페이지에 포함하되,
그 외 정보는 계속 비공개로 유지한다.

- 이름(김지후), 나이(16세)는 본인이 직접 공개를 요청해 포함되어 있다.
- 소속 학교명, 실제 연락처(이메일/SNS 등), 실제 사진은 게시하지 않는다.
- 사진 자리에는 실제 사진 대신 CSS로 그린 이니셜 아바타를 사용한다.
- 소속은 특정 학교명 없이 "중학교 졸업을 앞둔 학생"과 같이 일반화한다.
- 연락처는 실제 정보 대신 "담당 선생님을 통해 연락"과 같은 안내 문구로 대체한다.
- 콘텐츠를 수정할 때도 이 규칙을 유지하며, 규칙을 변경하려면 명시적인 요청이 있어야 한다.

## 현재 상태
초안 작성 단계이며 배포는 진행하지 않았다.
